# RO製薬計算機

ラグナロクオンラインのアイテム作成に必要な材料を確認するための個人制作Webツールです。

## 公開サイト

https://menorca1223-dev.github.io/ro-pharmaceutical-calculator/

## 使い方

1. 製薬種類を選択
2. 完成品を選択
3. 作成個数を入力
4. 「計算する」を押して必要な材料を確認

材料によっては、カーソルを合わせることで入手方法や作成方法を確認できます。
